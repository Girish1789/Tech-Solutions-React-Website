Step 2: motion.div

<motion.div>
Ha normal React div sarkhach aahe, pan Framer Motion mule tyala animation deta yete.
Mhanje apan ya element la sangto ki scroll kartana kasa disaycha ani kasa move vhaycha.
Step 3: key={item.title}

jsx
key={item.title}
React la pratyek card olakhnyasathi key lagte.

Step 4: initial

jsx
initial={{ opacity: 0, y: 100 }}
He animation suru honyapurvichi state aahe.
opacity: 0 — card suruvatila invisible asel.
y: 100 — card tyachya normal position peksha 100 pixels khali asel.
Animation suru honyapurvi
Normal position
Card: y = 100
Opacity = 0
Mhanje card khali aahe ani disat nahi.
Step 5: whileInView

jsx
whileInView={{ opacity: 1, y: 0 }}
Ha animation cha destination aahe. Card screen madhye disayla lagla ki Framer Motion tyala ya state kade animate karto.
opacity: 1 — card purnapane visible hoto.
y: 0 — card tyachya original position var yeto.
Animation purn zalyavar
Card smoothly var yeto
Opacity = 1 · y = 0
Step 6: viewport

jsx
viewport={{ once: true, amount: 0.1 }}
He settings tharavtat ki animation kadhi suru vhaychi.
once: true — ekda animation zali ki ti punha honar nahi.
amount: 0.1 — card cha sadharan 10% bhag viewport madhye ala ki animation trigger hou shakte.
Jar pratyek veli scroll kartana animation punha havi asel, tar:

jsx
viewport={{ once: false, amount: 0.1 }}

1. User scroll karto

4. Card smoothly var yeto
whileInView + transition
